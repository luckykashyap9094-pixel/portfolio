# 🚀 Lucky Kashyap — Developer Portfolio

A responsive, interactive personal portfolio website showcasing mini-apps, front-end development skills, and dynamic tools.

🔗 **Live Website:** [lucky-hub07.netlify.app](https://lucky-hub07.netlify.app)

---

## 🛠️ Built With
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Features:** Dark/Light Theme, Responsive Modals, Sticky Navbar
* **Deployment & Hosting:** Netlify (Continuous Deployment via GitHub)
* **Form Backend:** Formspree API

---

## 🎮 Included Projects & Mini-Apps
1. **Interactive Calculator:** Arithmetic operations with keyboard/touch support in an in-page modal.
2. **Real-Time Digital Clock:** Live local time synchronization and formatted calendar date.
3. **Rock-Paper-Scissors Game:** Browser game featuring randomized choices and persistent round score tracking.
